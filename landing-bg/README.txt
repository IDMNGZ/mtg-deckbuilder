Drop landing-page background images here (jpg/png/webp/svg all work).

After adding a file, it also needs to be listed in js/landing-backgrounds.js
for it to actually be used - just add "landing-bg/your-file.jpg" to the
LANDING_BACKGROUNDS array. Easiest path: hand the image file to Claude and
say what it is - it'll add the entry and push for you.

One background from the list is picked at random every time the landing
page loads.
