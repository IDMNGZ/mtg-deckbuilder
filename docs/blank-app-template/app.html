Switch Profiles

Separate data for different people sharing this device - all backed up through the same Dropbox connection below.

    Manual Backup

    No account needed - move your data yourself.

    Export downloads a JSON file of your current profile's data. Import loads that file back in (on this device or another), merging it with whatever's already here. Works well dropped into any synced folder you already use - iCloud Drive, Dropbox, OneDrive, etc.

    Reset This Device

    Wipe every profile stored here and start fresh.

    For when this device's local data is corrupted or mixed up and starting clean is easier than fixing it by hand - doesn't touch your Dropbox account itself, only what's stored on this device. If Dropbox was connected here, reconnecting afterward pulls your data back down with nothing local left to conflict with it.
